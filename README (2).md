# Engineering Study App — content-first repository (draft)

Initial focus: PE Civil Transportation. GPT coordinates content, verification, product decisions, and AI handoffs. GitHub remote publication is pending account connection.

## Repository rules
- No publisher PDFs, screenshots, copied questions, copied diagrams, or third-party solutions in the public repository.
- These are original **drafts** inspired by underlying engineering skills. Originality and licensing require a separate review before release.
- Every question needs one unambiguously correct choice, independently checked calculations, valid units, realistic distractors, and the relevant standard's edition where applicable.
- A calculated result is not the same as an approved standards-based design value.
- Only approved questions may be imported to the production question bank.
- Each concept has a baseline and two alternative presentations; variations target transfer of knowledge, not cosmetic number changes.
